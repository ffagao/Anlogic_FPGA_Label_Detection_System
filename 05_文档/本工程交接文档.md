## 一、交付基线

本工程面向实时视觉处理与工业包装辅助检测，运行于PH1P35MDG324板卡。摄像头采集和ISP、目标颜色形状识别、标签检测、条码解码均在FPGA完成；上位机负责串口控制、遥测展示和订单资料查询。

本次只整理比赛交付材料，没有重新修改业务RTL或重新生成位流。位流与已交付的完整源码基线对应。上位机采用最新进阶2自学习入口和页面切换修复版。

## 二、硬件和数据链路

摄像头→CSI接收→ISP（包括自动曝光测光、去马赛克、自动白平衡及所选算法）→像素打包与DDR缓存→HDMI读出→检测与OSD叠加→显示器。

具体模块的处理域不同，以顶层连接为准；并非所有算法都在DDR前运行。采集、DDR与HDMI使用不同的时钟域，已有同步和握手逻辑必须保留。屏幕视频分辨率为1280×720，标签检测使用右侧ROI，左侧用于状态展示。帧率因模式和配置不同，按显示FPS核对，不宣称全部模式均为60FPS。

## 三、模式功能

| 实际模式 | 功能 |
|---|---|
| 0000 | 基础图像算法：彩色、边缘、灰度、二值化、直方图均衡、红色边缘；有直方图对比及OSD |
| 0001 | RGB颜色与三种形状的选择、识别标注及区域显示 |
| 0010 | 运动检测及变化连通区域估计 |
| 0011 | 颜色形状目标追踪，支持已学习颜色；可暂停/启动 |
| 0100 | 舵机回中和颜色自学习：预备、开始 |
| 0101 | 移动纸箱标签学习与检测、结果统计、PASS后侧面条码扫描 |

未定义模式不作为独立功能使用。请通过配套上位机选择有效模式，以板卡数码管、HDMI为实际状态依据。

颜色自学习与标签标准学习是两个独立功能。颜色自学习在0100执行；标签标准学习在0101执行，不要混淆。

## 四、标签与条码业务

先学习标准样本，再对进入ROI的单个盒子进行等待和间隔多帧判定，锁存PASS/FAIL/UNKNOWN，目标离开后进入下一轮。结果依赖盒体/标签有效成像、参考模型和姿态，不是任意复杂背景下的通用目标识别。

检测PASS授予一次扫码许可。人工拿起盒子，侧面对准摄像头，按K4或上位机按钮进入扫码。Code128 C读取六位订单，连续两次一致的解码结果用于确认；成功后显示查询信息并增加扫描计数。同一会话不会因重复解码反复加数。下一次检测后的重复订单仍可再次计数，当前不做跨会话唯一箱体去重。

条码不与原标签同时检测。FAIL和UNKNOWN无法进入扫码。没有按负责人分组的板卡计数。保留扫描总数和标签三类结果计数，清除或复位行为以现有按键逻辑为准；数据不保证断电保留。

## 六、串口协议与软件行为

串口115200、8N1，TX/RX交叉并共地。控制帧 `A5 OP LO HI XOR`，XOR为前四字节异或。常用OP04为模式/子状态直达，OP10为颜色形状场景，OP12为带模式上下文的按键。

| 操作 | HEX帧 |
|---|---|
| 标签主模式 | A5 04 50 00 F1 |
| 标签标准学习 | A5 04 52 00 F3 |
| 条码录入 | A5 04 51 00 F0 |
| 标签K1返回/检测 | A5 12 51 00 E6 |
| 标签清计数 | A5 04 55 00 F4 |
| 颜色学习预备 | A5 04 43 00 E2 |
| 颜色学习开始 | A5 04 44 00 E5 |

固件本身的有效条件仍适用，发送扫码命令不绕过PASS许可。界面“当前请求”不是固件对每条命令的应答。

遥测36字节：`A5 5A 02 SEQ MODE FLAGS REGIONS FPS DELAY CAP[3] DISP[3] BLOCKS[2] RESULT CAUSE PASS[3] FAIL[3] UNKNOWN[3] ORDER[3] SCANNED[3] RESERVED XOR`。末字节异或覆盖索引2～34。计数等数字字段为BCD，模式/标志/结果等为二进制。标志bit0运动有效、bit1容量溢出、bit2标签有效、bit3条码有效。RESULT为1 PASS、2 FAIL、3 UNKNOWN。

上位机按订单号本地查询详情，查询表必须与FPGA查表和打印资料同步。上位机兼容旧18字节遥测，但其不能提供新字段。

## 八、继续开发注意事项

像素数据、valid、帧行标志和坐标必须同步；不能只延迟像素而忽略控制。DDR写FIFO复位曾造成丢帧首像素和右侧错位，不要随意恢复旧复位逻辑。算法输出与显示链路的相位对齐必须做像素级验证。

修改订单映射时同步固件、UI和样张。UI离开页面后Qt会销毁旧控件，不能继续引用；最新修复在切页前清空自学习面板引用，并增加DeferredDelete重入测试。

## 九、已知限制

条码只支持本工程设计的演示编码范围和成像条件，不是通用工业扫码器。运动区域数是变化区域估计，不能保证等于真实物体数。延迟毫秒是帧龄估算，不是仪器端到端测量。上位机固定资源页已更新为交付位流的最终数据，数据来自构建报告而非板卡实时测量。
