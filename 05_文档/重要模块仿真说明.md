# 本工程重要模块仿真说明

## 文件位置与运行环境

所有testbench均在01_FPGA工程/tests内，标签辅助用例和参考模型在tests/label、tests/label/reference。文件名中的数字是历史测试编号，不是提交版本要求。被测业务RTL来自本包user_source，不使用未交付实验功能。

本次重新验证环境：Windows、ModelSim SE-64 10.7、Python 3。Python运行入口只依赖标准库，仿真需要已安装并可使用的ModelSim。不要直接在包含中文的完整路径下运行旧版ModelSim，应将整个01_FPGA工程复制到纯英文目录，例如E:/contest_fpga。只复制tests会缺少业务RTL和IP。

## 一键运行

在E:/contest_fpga打开PowerShell：

```powershell
$env:MODELSIM_BIN='E:/modelsim/win64'
python .\tests\run_key_simulations.py
```

请将MODELSIM_BIN改为本机包含vlib.exe、vmap.exe、vlog.exe、vsim.exe的实际目录。脚本创建仿真工作库、生成必要fixture、编译工程和testbench，逐项运行；出错会返回非零退出码。成功时每项输出PASS，末尾显示ALL PASS: 15。

单项测试示例：

```powershell
python .\tests\run_v34_tests.py tb_v42_dynamic_controller
python .\tests\run_v34_tests.py tb_v43_barcode_pixels
python .\tests\run_v34_tests.py tb_uart_telemetry
```

原run_v34_tests.py默认清单还包含历史回归；本次明确验证的是run_key_simulations.py列出的15项，不宣称所有历史测试均重新执行。已将动态标签和两项条码testbench补入编译列表，避免文件在包里但无法通过入口运行。

## 用例与验证目标

| Testbench | 被测功能与主要检查 |
|---|---|
| tb_v42_dynamic_controller.sv | 标签参考学习、间隔采样、短暂无效观测、移动坐标、结果锁存和离开后重置；仿真使用缩短后的定时参数 |
| tb_v43_barcode.sv | 无PASS禁止扫码、许可发放、双次一致确认、不同订单拒绝、重复解码不重复计数、退出后许可不能复用、新箱撤销旧许可 |
| tb_v43_barcode_pixels.sv | 用像素流验证Code128 C六位订单100001的实际解码；与注入解码结果的会话测试分开 |
| tb_uart_telemetry.sv | 36字节遥测帧、115200协议结构对应的8N1串行发送、字段与异或校验；仿真缩短时钟/波特参数 |
| tb_motion_region_counter.sv | 变化块连通区域计数逻辑 |
| tb_motion_regions_stream.sv | 视频流运动变化区域统计及发布 |
| tb_v34_video.sv | 视频链路相关控制与回归 |
| tb_v39_control.sv | 模式与串口控制场景回归 |
| tb_v41_caption.sv | 目标说明字幕、坐标/模式变化和显示行为 |
| tb_v41_metrics.sv | 形状度量与位宽优化数值对照 |
| tb_v33_learning.sv | 目标颜色自学习逻辑 |
| tb_v34_histogram60.sv | 直方图相关60帧场景回归 |
| tb_v20_ae_chain.sv | 自动曝光控制链路回归 |
| tb_v23_awb_green_bias.sv | 白平衡偏色修正相关逻辑；不是任意光源下的完整颜色精度验证 |
| label/tb_hud_cache.sv | 标签状态栏缓存与显示相关逻辑 |

## 波形与日志

运行后tests/sim_out存放本机生成的工作库和日志。使用ModelSim GUI将工作目录切到tests/sim_out，执行：

```tcl
do ../view_key_wave.do
```

该脚本默认运行动态标签控制测试，可修改set top为表中其他testbench模块名。观察clk、复位、sample/valid、state/result/locked、ticket/active/done及输出信号，具体名称以各testbench为准。run -all可能在测试结束后退出仿真，必要时先手动加载顶层并运行较短时间查看中间状态。

本次实际运行的文本日志已放在外层06_仿真验证记录，无需仿真器即可阅读。未打包体积较大的ModelSim工作库/数据库；工作库可从源码再生成。

## 本次验证结果与边界

2026-11-03：编译成功，15项测试全部PASS。此结果是RTL功能仿真，不替代综合、布局布线、时序签核或板级测试。缩短仿真定时参数不证明真实端到端延迟；条码会话用例使用注入的解码命中，只有像素流用例检查实际解码。实物摄像头、DDR模拟器、照明、印刷、舵机机械与串口接线仍需现场验证。
