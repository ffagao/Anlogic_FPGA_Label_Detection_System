# 本工程比赛提交包

整理日期：2026-11-03。目标器件：PH1P35MDG324，速度等级-3。

| 目录 | 内容 |
|---|---|
| 01_FPGA工程 | 完整HDL源码、IP、引脚与时序约束、仿真测试、TD工程、构建脚本和原最终报告 |
| 02_下载文件 | main_PH1P35MDG324.bit，可直接用于BitWriter下载 |
| 03_配套软件 | 上位机RAR包，含免安装程序、完整Python源码和说明 |
| 04_条形码资料 | 六位订单条码RAR包，含A4十枚PDF、SVG、打印网页和查询资料 |
| 05_文档 | 本工程交接文档、使用说明、验证与资源报告 |
| 06_仿真验证记录 | 15项关键模块本次实际运行日志；测试源码与入口在01_FPGA工程/tests |
| 07_关键模块仿真波形 | 4组波形PNG、ModelSim WLF/VCD、加载与采集DO脚本、testbench副本、日志及复现说明 |

首次使用请阅读05_文档中的使用说明。交接文档面向队友继续开发。工程内部文件、脚本和EXE保留历史名称，以避免破坏构建依赖；新增交接和使用文档均以本工程为描述对象。

07目录中的波形资料对应动态标签判定、条码像素解码、扫码会话控制和UART遥测四个测试平台。PNG展示关键波形；WLF可在ModelSim中加载，配套`*_load.do`脚本用于添加信号。波形由仿真数据绘制，纳秒时间为仿真时间；测试中的缩放参数和限制见该目录的仿真说明。日志中的编译警告统计亦保留供复核。

本工程扫码仅在标签检测PASS后允许；FAIL和UNKNOWN不允许扫码。本包不含未交付的负责人统计等实验改动。

上位机已包含进阶2颜色自学习专用按钮和反复进入页面的修复。视频在HDMI显示，电脑端显示控制与遥测信息。
